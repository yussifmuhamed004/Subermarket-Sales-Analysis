__🛒 Supermarket Sales Analysis __



📌 Project Overview

This project analyzes supermarket sales data to identify sales trends, customer behavior, product performance, and payment preferences.

The project demonstrates how SQL and Power BI can be used to transform raw sales data into meaningful business insights and interactive dashboards.

🎯 Business Questions

- What is the total sales generated?
- Which product lines generate the highest sales?
- Which gender contributes more to total sales?
- Which payment method is most commonly used?
- Which branches perform the best?
- What are the main customer purchasing patterns?

🛠 Tools & Technologies

- SQL – Data analysis and business queries
- Power BI – Data visualization and dashboard
- Excel – Initial data preparation
- GitHub – Project documentation and portfolio

🔍 SQL Analysis

The analysis includes queries for:

- Total Sales
- Total Quantity Sold
- Sales by Product Line
- Sales by Gender
- Sales by Payment Method
- Branch Performance
- Customer Type Analysis

📊 Dashboard

The Power BI dashboard provides an interactive overview of:

- Total Sales
- Total Quantity
- Product Line Performance
- Branch Performance
- Customer Demographics
- Payment Methods

💡 Key Insights

The analysis helps identify the best-performing product categories, understand customer purchasing behavior, and compare sales performance across different branches and payment methods.
